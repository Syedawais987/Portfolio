## Key Points for Freelance Videos

| Do | Don't |
|----|-------|
| Focus on client's needs | Talk only about yourself |
| Mention specific services | Be vague |
| Show confidence | Sound desperate |
| Include call to action | End abruptly |
| Mention response time | Overpromise |

---

## Services to Highlight

Based on your experience, emphasize:

1. **Shopify App Development**
   - Public apps (App Store)
   - Private/custom apps
   - Theme customization
   - Shopify integrations

2. **Web Development**
   - React / Next.js websites
   - Full-stack applications
   - API development
   - Database design

3. **Backend Development**
   - Node.js / Express APIs
   - PostgreSQL / Supabase
   - Real-time features (WebSocket)
   - Third-party integrations

---

## Recording Tips for Freelance Platforms

1. **Thumbnail:** Smile, look approachable
2. **First 3 seconds:** Hook them immediately
3. **Background:** Professional but not stiff
4. **Energy:** Friendly, enthusiastic, confident
5. **Pace:** Clear and easy to follow
6. **CTA:** Always end with "message me" or "let's connect"
